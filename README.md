# TowerTap Android

Android accessibility-based timer tap assistant and configurable screen-text trigger demo.

This project is a general-purpose accessibility automation sample. It does not predict gambling outcomes, interact with betting APIs, or guarantee game results.

## Build

Open this repository in Android Studio, or run the **Build APK** GitHub Actions workflow. The debug APK is published as a workflow artifact.

## Permissions

The app requires the user to explicitly enable its Accessibility Service in Android Settings. Use it only in apps and contexts where automation is permitted. The service has a visible stop control and should be disabled when not in use.
